How a file becomes a verdict

The pipeline has six stages: read the file, prepare the evidence, run the detectors, combine their scores, grade the confidence, and write the report. Click a stage for details.

How the verdict is decided

The order matters. This is the logic in the engine's judge, in plain language.

1

Does the file declare itself AI-generated?

An explicit generator marker (Stable Diffusion's PNG parameters, IPTC trainedAlgorithmicMedia, a generator name in Software) is self-declared provenance. The result is fake with at least 97% fake probability, and the report says why.

2

Are any trained pixel detectors available?

If none can run, the answer is no verdict. The engine never fabricates a guess from nothing. If only one of the two detectors is available, it uses that one and lists the other as skipped.

3

Fuse the detector scores.

The CLIP and frequency scores go through a class-balanced logistic regression. The decision point is shifted so that about 10% of real training images would be called fake, because a false accusation is worse than a miss. Metadata applies only a small nudge.

4

Call it, then grade the call.

The verdict is always likely real or likely fake. Separately, a confidence level of high, medium or low says how much to trust it, and low-confidence results carry a stated reason.

What raises or lowers confidence

Confidence is the product of these four factors, so weakness in any one pulls it down. Below 0.30 is low, 0.30 to 0.55 is medium, and 0.55 or above is high.

Margin

How far the fused score is from a coin-flip 50%. A 52% result is barely an answer.

Agreement

Do the detectors tell the same story? Strong disagreement (a spread above 0.6) forces low confidence.

Input quality

Heavy JPEG compression, low resolution (under 256px), or no visible face all discount the result.

Coverage

Did both pixel detectors run? A missing detector lowers confidence and is listed as skipped.

Why report it. A result that is 60% likely should not read like 99%. The stated reason, such as “detectors strongly disagree” or “file was recompressed”, tells you what to do next.

What the report contains

This is the shape of what the engine returns for an image, and the website renders these fields directly. The values are an example, not a real analysis.

{
  "authenticity": 0.86,
  "verdict": "likely_real",
  "summary": "REAL (authenticity 86%). ...",
  "assessment": {
    "confidence": "medium",
    "agreement": 0.82,
    "input_quality": "good",
    "detectors_used": ["clip_probe", "frequency"],
    "detectors_skipped": [{ "name": "ela",
      "reason": "file was recompressed" }]
  },
  "signals": [{
    "name": "frequency",
    "score_fake": 0.21,
    "finding": "Frequency spectrum looks like that of
                camera-captured images."
  }, ...],
  "caveats": ["Editing analysis (ELA) is not used ..."]
}

score_fake: 0 means real, 1 means fake, for that one detector.

finding: a plain-English sentence. If you can't explain a score, you can't defend it.

heatmap / time_ranges: where in the image, or when in the clip, the detector looked suspicious, when it can say.

reliable: false: a detector can mark itself “not used”. ELA does this when compression has erased its evidence.

caveats: limits of this result, shown next to the verdict, never buried.

Engineering rules

✓
Split by source, never by frame.Train and test sets are split by source video or person, so the same face can't appear on both sides. The loader refuses a manifest that leaks.
✓
Report seen vs. unseen fakes.A detector's score on generators it trained on flatters it. We always show the unseen column too.
✓
Report false positives on real content.Accusing a real photo is the costly error, so its rate is a headline metric.
✓
Every detector returns a finding.A score, a plain-English reason, and a heatmap or time range where possible.
✓
Local-first compute.The engine picks the best available device at runtime and falls back to CPU, so it runs on an ordinary computer.
✓
Data and checkpoints stay out of git.Features are cached to disk, and each detector has a small test.
