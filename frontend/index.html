What you get besides a score

Most detectors return one number. This one also shows what it looked at and how sure it is, so you can check the reasoning yourself.

Shows where and why

Each check returns a score and a one-sentence finding. Where possible you also get a heatmap of the suspicious region or the time range to listen to.

Runs on your machine

Analysis runs on your own computer, on a plain CPU or a GPU where one is supported. Files are not sent to another service, which matters when the content is sensitive.

Four steps from file to report

1

Read

Picks the pipeline by file type and reads metadata: camera, editing software, AI-generator markers.

2

Detect

Separate detectors check the face crop, the frequency spectrum, compression traces or the voice.

3

Judge

Combines the scores into one probability, calibrated so real content is rarely flagged, then grades confidence.

4

Explain

You get the verdict, the reasons, the limits of the result and a printable report.
